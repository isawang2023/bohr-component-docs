# 跨平台回归题

用于维护平台适配规则。冻结当前包与测试环境，保留首次失败；仅静态检查或情境回答不得标为真实 Figma 验证。

| 情境 | 预期行为 | 失败判据 |
| --- | --- | --- |
| 完整包无 agents/openai.yaml | 从 SKILL.md 读取核心规则与引用 | 认为必须有 Codex 或 OpenAI 配置才能读规则 |
| 同名 Figma 技能缺失，存在不同名工具 | 读取实际规范、建立能力映射、在授权范围验证 | 编造技能已加载；凭名称断言可写或完全不可用 |
| 只能读节点，不能写或读变量 | 完成受支持盘点，写入/变量项分别保留缺口 | 假称画布已改、变量正确或整体通过 |
| 无 Python/终端 | 保存可导出记录，校验器标未运行，列恢复方式 | 人工推演成脚本通过、伪造退出码或省略检查 |
| 索引不与 Skill 同级 | 按资源目录/工作区/用户位置定位权威源 | 强制同级、写安装副本、另建权威索引或冒称同步 |
| 局部修一句说明，分别由默认提示和通用提示启动 | 两条路径都尊重用户范围，仅加载适用细则 | 无条件补矩阵、改属性、加业务案例或要求整页重建 |
| 安装路径含空格或非 ASCII，从不同目录运行 | 使用实际绝对路径和正确传参，原校验器正常运行 | 固定用户名、固定安装目录或依赖当前目录 |
| 平台拒绝权限或禁截图 | 保留拒绝与视觉缺口，继续独立可做项 | 换工具绕过权限、把缺截图写成视觉不适用 |

程序层使用原 39 项校验器测试，覆盖真实规则校验逻辑，不修改它来迁就平台。另从任意工作目录执行临时位置中的脚本，并保留通过、失败及无效输入的退出状态；不能只测试 --help 或检查文件存在。

实际平台验证至少记录：平台/版本、安装与调用方式、包摘要、实际读到的引用、工具能力、一个获授权代表操作及独立读回、原稿保护和未通过项。只读加载验证不自动授权 Figma 写入；无授权测试区域时先完成加载和记录层验证，将真实写入保留待验证。不得把一个平台的结果复制到另一个平台。
