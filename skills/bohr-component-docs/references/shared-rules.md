## 共同分析的常见组合
| 组件组 | 共同判断 |
| --- | --- |
| Field、Label、Input、Textarea、Input Group | 标签、辅助说明、必填、校验与附加操作 |
| Checkbox、Radio Group、Switch、Toggle、Select、Combobox | 单选、多选、即时切换、搜索选择 |
| Dialog、Alert Dialog、Popconfirm、Drawer、Sheet | 决策重要性、内容承载、触发与关闭 |
| Popover、Hover Card、Tooltip | 点击操作、内容预览与辅助解释 |
| Alert、Sonner、Empty、Result、Progress、Spinner、Skeleton | 持续提示、短暂反馈、无内容、结果与加载 |
| Table、Data Table、Pagination、Descriptions | 数据结构、组合交互、分页与详情 |
| Badge、Tag | 状态、计数、选择与移除 |
| Calendar、Date Picker | 日期输入、范围与预设 |
| Accordion、Collapsible、Tabs、Sidebar | 展开、内容切换与导航 |

这是分析线索，不是固定合并清单。先读实际组件说明和使用方式，保持组件身份与原资产。Composer 等业务组合不强行当作普通 Input，先分析输入、引用、文件、任务状态及工具选择的关系。

## 冲突记录
记录“来源A的原要求／实际值、来源B的原要求／实际值、适用条件、影响、待决定项”。不把观察包装为规范，也不把自己的建议标为已确认。
