# 现有模块组件抽样记录

用于把业务模块中的组件线索接入 `bohr-component-docs`，不替代组件专文，也不代表组件库发布。

| 字段 | 记录内容 |
|---|---|
| 来源 | Figma 文件、页面/Frame、节点 ID、平台、主题、日期 |
| 抽样目的 | 要确认的复用问题或文档范围 |
| 候选对象 | 原名称、英文原稿、技术标识、中文说明 |
| 分类 | 基础组件 / 业务组合 / 模块预设 / 局部例外 |
| 组件证据 | `INSTANCE`/组件集、主组件链路、变体轴、默认值 |
| 状态与内容 | 已观察状态、长文本/窄宽度/错误等实际案例 |
| 绑定证据 | Variable、Text Style、Paint、图标包装与颜色变量 |
| 结论 | 已确认 / 建议复用 / 未验证 / 不建议抽离 |
| 接入位置 | 组件专文、场景案例或仅保留来源记录 |
| 缺口 | 需要定向核实的属性、行为、线上证据或字体/资产问题 |

规则：保留英文原稿和技术标识；不要把样本中的文案、日期、数量、状态名直接升格为业务规则；不要因为抽样完成就批量重命名、合并、发布或改动源组件。
