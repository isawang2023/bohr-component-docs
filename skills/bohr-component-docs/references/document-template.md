# 内容与视觉模板

## 模板来源与锁定

分别锁定三类参照：**视觉模板**负责排版与角色；**目标组件能力/案例参照**负责实际组合、状态和案例覆盖；**线上产品来源**负责业务事实。用户本次指定的参照优先，记录各自职责；不能用通用模板外框一致代替目标组件案例齐全，也不能用原库样例代替线上取源。

生成前依 [任务清单](task-evidence.md) 逐例盘点参照，记录源节点、mainComponent链、属性/状态、可见内容、主题、尺寸及案例内部组合关系；每例对应目标节点和验收项。数量相同不证明主组件或状态相同。完整组合不能以独立子组件替代；确需调整时先记录用户授权或当前来源依据。新增业务案例单独关联，不抵消基础案例缺失。外框、Header、Footer通过不代表Preview通过；不得把某次参照的案例数量或间距硬编码为所有组件标准。

选用顺序：用户当前指定模板 → 当前组件库已确认模板 → 候选模板。现有组件页可以作为候选证据，但“最近整理过”或“看起来完整”不代表已确认。找不到已确认模板时，不把某一页的宽度、字体或三张展示板自动提升为标准。

查到会话或项目中明确适用的确认即可复用，无需反复确认。来源冲突只询问影响模板选择的决定；先交付内容盘点和一个具体候选，不能空问“你要什么样式”。

在本地交付记录保存一份模板锁定记录：

| 必需记录 | 内容 |
| --- | --- |
| 身份 | 模板 ID、版本、Figma file/node 链接、读取日期 |
| 确认 | 已确认或候选；可追溯的用户决定或项目规范 |
| 适用范围 | 组件库、语言、主题、本次组件列表 |
| 结构 | 栏目节点、顺序、表头、实例容器、对照位置、维护区 |
| 布局 | 页宽、内容宽、边距、分区/卡片间距、方向、自动布局与宽高策略 |
| 排版 | 每个文字角色的字体、字重、字号、行高、文字样式 ID |
| 视觉 | 颜色/变量、主题模式、边框、圆角、阴影、图标、预览容器 |
| 可变范围 | 可增加的数据行/案例、换行和高度增长方式 |

保存实际读取值与节点，不能只写“同 Input”。每个组件引用同一版本，不能混用 A 页字体、B 页卡片和自定页宽。组件本体的尺寸与字体不因文档模板被改造；一致性针对文档角色与容器，不要求 Input 与 Composer 本体长得一样。

## 内容字段与画布映射

以下字段用于完整性检查，不规定画布表格或栏目数量。先建立“字段 → 模板位置”映射，可放在正文、示例、来源链接或维护记录中，但不可遗漏。可见标题、分区和卡片以参考模板为准；局部更新不为补全检查表而重建整页。

### 组件身份与来源

组件身份标题使用 `EnglishComponent / 中文名`；规则文档如 `Checkbox Rules / 复选框规则`，示例文档如 `Checkbox Examples / 复选框示例`。英文标识取已核对的组件族，不凭中文反向猜译；新增族的英文标识先登记确认。详见 [Figma 命名规则](figma-naming.md)。

组件名/中文名称、用途一句话、适用与不适用范围、来源节点与日期、原稿语言、内容状态、模板版本。无英文标“新增整理”，不补造英文。

### 组件属性与变体

| 属性名称 | 原技术标识 | 类型 | 可选值 | 默认值 | 中文含义 | 示例/来源节点 |
| --- | --- | --- | --- | --- | --- | --- |

实际没有公开属性时保留一行“未暴露”，不把说明文字变成属性。组合组件在此栏目补“组成 / 职责 / 关联组件节点”，不合并或重造源组件。示例尺寸不作为全局约束。

### 基础用法与示例

每个案例覆盖：**案例名、使用条件、实际属性/组合、可编辑实例预览、选择理由、边界/例外、来源及验证状态**。字段可合并为符合参考层级的短说明；排列和视觉角色按模板，不机械生成七行标签或白色卡片。

完整整理至少覆盖一个正常用法及一个相关边界案例；简单组件可在同卡展示，不强造不存在的变体。缺口按模板的状态样式注明原因，不假称已覆盖。状态与主题覆盖范围取自任务与来源，不为统一数量编造案例。

实例与说明须按模板进入同一布局结构，文本增长能推动预览及后续内容；主组件在约定资产区。不得用页面级浮动实例覆盖空白卡片，不以普通 Group 代替模板要求的自动布局。来源链接不能替代预览。

### 业务场景与使用规则

| 操作目的/条件 | 选择与原因 | 例外 | 依据类型 | 来源/案例 |
| --- | --- | --- | --- | --- |

依据类型为已确认、观察现状、整理建议、待确认。Web/桌面端对照保留同一字段：操作目的/条件、Web 证据、桌面端证据、对照结论、覆盖边界。无业务专属规则可写“不适用：仅遵循所引用的公共规则”，不能删入口。

### 验收与待确认（维护区）

内容、形式、场景验证各自状态；来源冲突、影响、待决定项、恢复条件；本次范围及模板版本。工具调用、完整报错和长验证日志留在本地证据记录，以链接引用。

## 形式的固定与可变部分

| 固定，必须与模板一致 | 可随组件改变 |
| --- | --- |
| 模板的可见分区、表格或叙述形式、导航及页脚 | 章节主题、真实属性值、行数、来源、规则、文案 |
| 页宽/内容宽、边距、文字层级、颜色绑定、边框、圆角、主题策略 | 文本按模板换行，内容高度随布局增长 |
| 预览容器结构、实例复用方式、说明与预览的布局关系 | 原组件自身形态、案例数量、实际支持的状态 |
| 同批次同一模板版本 | 业务组件在规定位置增加组成与流程说明 |

复制/复用模板优先；无法复制时，重建必须逐项对照模板，不能只采样字号和页宽。英文原稿保持原样，中文置于锁定对照区；不因英文页各不相同而生成多种中文模板。空间不足向空白区域延展，或仅作必要的相邻位置调整并记录。

## 完整复用与层级对照

复用次序：现有文档组件/容器 → 克隆完整参考结构后替换授权内容 → 无法复用时按节点清单重建。自绘文本和边框不能称为 Header 实例复用。克隆后核对文字和链接，清除不适用的 Button 专属内容，保留版权和许可。

分别检查页标题、类别标签、简介、章节标题、案例标题、属性注释、正文、脚注。逐角色记录字体、字重、字号、行高、字距、颜色/变量、paint opacity、节点/父层 opacity、尺寸及对齐。相同字号不代表相同层级。

结构清单包含 Container、Header、Preview/Wrapper、主题容器、贯穿内容的边界线、分隔线、Footer/Description/Wrapper。装饰线允许按参考绝对定位，但须跟随页高更新；不能据此允许业务实例浮动拼贴。页脚文字和主内容使用同一对齐轴。

规则页与示例页分别映射；不把规则正文 18/28 套到所有示例标题。角色缺少参照时记录缺口，不使用上一级标题代替。

## 异常不改变模板

| 限制 | 允许继续 | 不允许作为最终交付 |
| --- | --- | --- |
| 字体不可加载 | 保留原字体；整理文案、来源及不受影响区域 | 未批准即换字体；缩小字号解决换行 |
| 实例无法进入预览容器 | 保留源实例；记录受限步骤及恢复条件；完成内容草稿 | 链接/图片替代实例；浮动实例与说明拼贴 |
| 无线上证据 | 保留对照字段，明确端侧与范围未验证 | 删场景栏目；把设计图称为线上证据 |
| 无已确认模板 | 盘点并形成一个候选供审阅 | 每组件各选模板；批量创建并标完成 |
| 既有版式与标准冲突 | 保留原稿，列差异，按已有授权迁移文档 | 改主组件或覆盖用户内容来强行对齐 |

用户明确要求替代字体或其他例外时按授权执行，记录例外或模板版本变更；不得外推为整个组件库的新标准。若目标是整库统一，列受影响文档与迁移范围，迁移完成前不称全库一致。
