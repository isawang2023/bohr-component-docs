# 图标来源验证用例

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| I01 | Bohrium 库中搜索到的图标实例，含 library/component key | 通过 |
| I02 | `Bohr icon/Wrapper` 暴露 `Bohr icon` INSTANCE_SWAP，最终实例可解析到批准的 Bohrium 图标 | 通过，记录完整链路；单有 `IconPlaceholder` 不通过 |
| I03 | `VECTOR`、`BOOLEAN_OPERATION`、SVG 或复制路径 | 失败 |
| I04 | Material、HugeIcon 或其他库实例 | 失败 |
| I05 | 节点名称像库图标但没有 key、remote 或搜索证据 | 失败 |
| I06 | 库搜索没有精确匹配 | 阻断并标记未找到，不允许猜测替换 |
| I07 | 外层业务组件为本地实例，但嵌套最终图标是批准库实例 | 按链路通过；外层本地组件不能被误判为图标来源 |
| I08 | 只检查最外层，漏掉嵌套矢量或图标实例 | 失败，要求补齐遍历范围 |
| I09 | 图标实际绘制的 fills/strokes 均绑定批准的颜色变量并记录模式 | 通过 |
| I10 | 图标有硬编码 RGB/HEX、未绑定 Solid Paint 或隐藏色值覆盖 | 失败，红线阻断 |
| I11 | 图标来源正确但颜色变量缺失/模式错误 | 失败，不能因来源正确放行 |
| I12 | `Bohr icon/Wrapper` 的 `Bohr icon#...` 属性指向批准库图标 | 通过 |
| I13 | 直接放置 `Icon/...`、`folder`、`HugeIcon` 或 `IconPlaceholder → HugeIcon` | 失败，绑定位置红线阻断 |
| I14 | 用户要求以英文图标为准，中文仍引用英文的 Lucide 或其他原库图标 | 失败；英文只作为功能参照，必须查找玻尔对应资产 |
| I15 | 引用的是玻尔图标，但密码、邮箱、复制、刷新等统一变成搜索或箭头 | 失败；库来源正确不能抵消功能语义丢失 |
| I16 | 逐项语义映射、玻尔库 key、Wrapper 属性、fills/strokes 变量与浅深主题全部核实 | 通过 |
| I17 | 未找到明确对应资产，继续沿用原图标或默认占位图标 | 失败；记录缺口并阻断该项 |
| I18 | 可见状态使用玻尔资产，隐藏状态仍残留外库图标或错误映射 | 失败；补齐递归显隐状态验收 |
| I19 | 图标 key 正确，但父层缩放、尺寸覆盖或显隐使原功能无法识别 | 失败；修复父层约束并回读、截图复核 |

验证时保存节点清单、Wrapper 属性值、搜索返回值、实际绘制 fills/strokes 的变量绑定、变量 ID 和模式；脚本退出成功、图标名称相同或截图无明显差异都不能替代这些证据。

### I27 · Scale 基值与实际描边不可直接判等

输入：用户批准 24px Wrapper 经 Figma Scale 到 16px，保留 Size=24/24px 模式；变量解析 1.8、实际描边 1.2000000477，内部几何为原值 2/3，颜色绑定不变。
预期：通过本项。按基值 × Scale 比例比较；不得要求实际描边等于解析基值，不得擅自切到 Size=16 或把线宽写死。12px 同理预期 0.9。重复执行应使用目标尺寸/当前尺寸，不能再乘 16/24。
真实证据：用户参照 28706:20773；修复测试 28705:2920 的 24/16/12 三项已逐层对照尺寸、描边、颜色和绑定。

### I28 · 嵌套实例不能直接Scale

输入：已有16px嵌套Wrapper不能rescale，内部路径已按源24px缩至2/3，当前尺寸模式解析1.2而实际0.8；允许修改此目标，源绑定可追溯。
预期：保留失败记录，不detach、不强行切Size=24使外框膨胀。仅在证据满足受限迁移条件时，修正目标描边基值模式，读回实际1.2及不变几何，再检颜色、显隐与重复swap；不修改共享变量。没有内部几何/绑定证据时阻断该迁移。

预期：报告526个图标实例（42可见、484隐藏）并附根节点链接；主组件去重后另报图标种类，不称526种或新建526个。Wrapper和内部图标不重复计数；完整祖先链上的隐藏容器必须被计入。
