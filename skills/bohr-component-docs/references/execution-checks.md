# 执行检查与失败恢复

在写入前读取。本流程落实已有模板、组件和图标规范，不新增设计数值，也不扩大局部请求为整页改造。检查记录与工具错误保存在本地，不插入使用者文档正文。

## 先跑通一个实际单元

选择本次要改的一个实例、状态或文档区块，记录其源、目标、保护范围和预期差异。在授权目标或测试副本执行实际需要的操作：创建/克隆、插入、属性或文字编辑，然后回读父链和最终内容。某一步成功只证明该步，不推定后续可行。

文字编辑前检查拟操作子树实际使用的字体和字重，包含隐藏、嵌套文字及混合字体区段；只加载拟操作所需字体。加载成功还需实际编辑验证；某字体失败不代表整个文件的文字都不可编辑。继承已有字体不等于获准替换字体。

代表单元通过受影响检查后再批量应用；后续实例仍按实际状态逐项核对，不能拿首个样本代替全量检查。插入、文字编辑或关键读回失败时，停止扩展该路径，继续不受影响项。

## 修改后立即读回

每项保存「目标节点/状态 → 预期 → 实际值或操作结果 → 证据位置 → 验收状态」。证据必须来自本次操作后的结果；再次修改会使受影响的旧通过记录失效，重新读回后才能恢复。预期值取当前批准来源，不照抄历史用例数值。

| 本次动作 | 随动作完成的检查 |
| --- | --- |
| 创建、替换或缩放图标 | 按 [图标引入检查](icon-provenance.md#引入后强制检查) 读回最终主组件链、Wrapper 与槽位的实际尺寸、内部几何/描边、绘制 Paint 绑定及父层覆盖；遍历受影响状态，包括隐藏子树。swap 成功不代表尺寸迁移成功。 |
| 修改主题或颜色 | 按 [颜色流程](icon-color-workflow.md) 分别检查语义绑定、模式解析和有效透明度；同时检查真实背景及嵌套容器，并在同一案例的亮暗容器中作视觉对照。变量解析正确不能代替可读性检查，透明背景截图不能证明完整 Dark 界面。 |
| 填充模板或状态矩阵 | 将所需分区、实际变体及有可见差异的 Boolean 对照与目标清单逐项核对；检查每个必需预览内的真实实例及其主组件。空槽位、标题或来源链接不能计为已完成示例。 |
| 编辑正文或布局 | 按 [可维护性验收](acceptance.md#c-实例与可维护性) 在副本测试正常/长文重排，记录预览与后续内容的位置、裁切和重叠，并保存所需同倍率视觉对照。文字写入失败不能记为长文测试通过。 |
| 修改组件属性、默认值或抽取组件 | 按 [组件抽取规则](component-extraction.md) 新建真实实例，核对实际显示文字/计数和默认属性，再从合法编辑入口修改。属性定义存在或主组件截图正确，不证明新实例内容及嵌套编辑可用。 |
| 重复整理或抽取 | 比较前后完整路径、主组件 ID/key、实例引用、数量和用户覆盖；重复图标 swap 只证明图标操作稳定，不代替重复组件构建或文档整理。 |

只检查本次适用范围；不适用项写理由。不能因为某项受阻、难以读取或缺截图就标为不适用。原稿与共享依赖保护按写前基线和写后实际字段比较，不能以未直接写入推定完全不变。

## 失败后先确认现场，再决定恢复

保存首次请求、错误原文和已知提交状态。工具明确未提交且可安全重试时按其声明处理；其他情况先只读核对本次节点是否存在、所在父链及已完成变化，避免重复创建。只清理身份和归属已确认的本次临时节点，不删除原稿或用户内容。

| 失败类型 | 恢复与停止条件 |
| --- | --- |
| 字体加载或文字写入失败 | 区分 load、append、characters 的实际失败步骤与目标；保留字体及原内容。只有可验证的前提改变后再尝试，例如所需字体已可加载；不静默换字体、缩小字号或改模板。 |
| createInstance/clone 成功但 append 失败 | 查明新节点是否留在 page 或其他父容器，保存其 ID；恢复必须证明实际进入预期容器及父链。浮动实例不算预览完成，后续属性转接能力也不能在尚未合法嵌套时下结论。 |
| 返回超限、截断或读取字段报错 | 先检查当前节点类型/API 支持，只返回必需字段。实例属性通常仅取 type/value，定义取 type/defaultValue；不返回无关的庞大元数据。按完整节点批次或子树拆读，保留 ID、范围、总数并检查缺漏/重复。截断结果不作全量证据；没有完整记录不宣称已全量检查。 |
| 截图/下载失败 | 保留已取得的结构证据，视觉项仍未验证；可以使用当前工具实际支持的其他图像返回方式，不能将结构检查升级为视觉通过。 |
| 审批拒绝或权限不足 | 停止被拒动作，保存原因并说明受影响范围；不通过改接口、换工具或相同重试绕过。可继续只读检查及独立的本地整理。 |

重试必须有新的依据或改变了导致失败的输入/读取方式；同一错误在有据修正后再次出现，停止这条自动重试路径并列恢复条件，不无限试参数。恢复后复查原失败项及修复可能影响的项目，保留首次失败，不覆盖成“首次通过”。

## 收尾

按 [统一验收门槛](acceptance.md#完成判定) 汇总检查记录。真实产物、局部机制、故意注入负例、历史记录复核和情境推演分别标明；未复现题设条件不记该题通过，最小夹具不代替完整业务交付。
