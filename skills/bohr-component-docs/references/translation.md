# 术语与翻译规则

## 英文原稿保护（写入前后必检）

- 原英文组件、说明及其技术标识、属性、代码、版权、链接均为保护对象；下文的翻译仅作用于指定中文区域，不能就地覆盖英文。
- 写入前记录英文保护节点、中文可写节点和共享依赖；保存文字、属性定义/值、实例主组件链、布局/样式与变量绑定的基线。页面过大时分段读取，缺失范围不得默认为已保护。
- 中文优先使用实例文字覆盖和 INSTANCE_SWAP 等原生能力。若必须改共享主组件内部，先建立符合唯一路径规则的中文专用主组件与实例关系；禁止 detach、复制外观或修改共享变量/样式绕过保护。无法隔离则停止受影响操作，继续独立项。
- 写入后比较保护对象的内容、结构、引用、样式和关键变量解析值；英文零非预期变化才通过。发现变化先记录差异，只有确认属于本次误改且无后续用户修改时恢复；存在冲突不得整页回滚覆盖用户内容。
- 不因“修中文”“以英文为准”“统一图标”而推定允许改英文。中文图标替换遵守玻尔资产规则，英文原图标原样保留。

## 翻译边界
可见标题、正文、提示、状态名、示例按钮文案译为中文；实例名称、组件名称、属性键和值、变量、代码、链接目标不改。比如画面可显示“主要按钮”，属性仍保持 Variant=Default；spacing/4 保持原样。
版权名称、年份、来源和许可链接保留。文档链接的显示文字可翻译，链接目标不变。占位数据与真实业务事实分开。

开始时提取全部可见文字及其节点与上下文，逐项记录译文与处理状态。实例中的文字也要覆盖；复制后检查嵌套实例已被读取。不能以“仅翻译到顶层三段文字”代表完成。隐藏文字按任务范围处理，避免修改无关状态。

## 默认术语
以下是翻译起点；文件已有明确词表时优先按该项目口径，并记录差异。

| 英文 | 中文显示 |
| --- | --- |
| Components | 组件 |
| Playground | 用法示例 |
| Developer docs / Designer docs | 开发文档／设计文档 |
| Default | 默认；当描述按钮操作层级时可写“主要按钮” |
| Secondary | 次要 |
| Outline / Ghost | 描边／幽灵 |
| Destructive | 危险操作 |
| Hover / Focus / Pressed | 悬停／聚焦／按下 |
| Loading / Disabled | 加载中／禁用 |
| Selected / Checked | 已选中／已勾选，按控件语义区分 |
| Small / Large | 小号／大号 |
| Full radius | 全圆角 |
| Placeholder | 占位提示 |
| Read-only | 只读 |
| Send / Learn more / Please wait | 发送／了解更多／请稍候 |

Badge 与 Tag 根据用途区分为徽标／标签；Dropdown Menu、Select Menu、Combobox 分别表达操作菜单、选项选择、带搜索建议的组合输入，不能只因都有下拉外观而合并术语。
Drawer 与 Sheet 的中文命名需结合项目既有用法，避免中文同名掩盖两类组件的差异。

## 语义检查
- 原文疑似拼写错误可正确翻译可见文案，但不要顺带改技术标识。
- 同名尺寸不代表同高；以实际变体记录尺寸，差异单列。
- “只支持PDF且不超过100MB”等先辨认是否示例。无确认依据时，不写成玻尔上传限制。
- 通用介绍无需加入未经证实的交互能力或性能承诺。
- 文案需要换成业务内容时，区分“原文中文对照”和“业务示意”，不要悄悄改变原意。
