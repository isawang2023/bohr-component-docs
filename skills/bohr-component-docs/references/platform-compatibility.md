# 跨平台使用与能力核对

首次在某平台使用，或平台版本、工具、权限变化时读取。通用规则只有一份；平台差异只改变加载、连接和执行方式，不改变组件来源、原稿保护、可编辑实例、Token、业务证据及验收标准。

## 加载方式

| 平台条件 | 使用方法 | 必须确认 |
| --- | --- | --- |
| 支持 Agent Skills 目录 | 将完整 `bohr-component-docs` 目录放入该平台支持的位置，按平台方式选择 Skill | 当前会话实际读到了本版入口及按需引用；安装成功不代表已加载 |
| 不支持 Skill，但可读取文件或资源包 | 用下面的通用提示明确读取入口和相关文件 | 不能只粘贴入口并丢弃引用、程序；资源返回须可读全 |
| 只接受附件、没有文件工具 | 提供完整资源并确认能检索其中相关文件 | 不能读取的部分明确列缺口，不能称完整运行 |

通用启动提示（不依赖 `$` 或 `/` 调用语法）：

> 使用所提供的 bohr-component-docs。先读取 SKILL.md，再按任务读取对应说明。核对当前平台所需的文件读取、Figma 操作、独立读回与程序执行能力。仅在指定范围工作，保留原稿及用户修改，报告实际结果与缺口。任务和目标位置以本次用户输入为准。

`agents/openai.yaml` 是可选的 Codex 展示/启动配置，其他平台不需要解析它；删去它不能删掉核心流程。`AGENTS.md`、平台专用命令和默认提示是否生效取决于平台，不能假定跨平台自动触发。不要复制某平台的权限放行设置来规避另一平台的确认机制。

## 操作规范与能力映射

已有 `figma-use` 时先加载；组件构建已有 `figma-generate-library` 时一并加载。没有同名技能时，先读取平台提供的工具文档及组件构建规范，按下表逐项记录“所需操作 → 实际工具/接口 → 输入和返回字段 → 实测证据 → 状态”。对应规范或能力缺失则停止受影响的写入，不能把同名技能不存在等同于所有能力不存在，也不能把不同名称等同于能力已满足。

| 任务需要的能力 | 必须验证的实际结果 |
| --- | --- |
| 读取节点与属性 | file/page/node 身份、完整路径、节点类型、真实属性与默认值；可分区读取且记录遗漏范围 |
| 检索批准资产与实例来源 | 可用库、组件 key、实例主组件链及 Wrapper/INSTANCE_SWAP；不能只返回名称或图片 |
| 读取变量与主题 | 实际绘制 Paint 的绑定、语义变量、模式解析、父层覆盖及嵌套背景；缺字段不猜测 |
| 授权写入与实例构建 | 在获准代表单元创建/复用真实实例、合法编辑属性与文字、设置主题、正确父链；图标缩放等能力按实际任务另验 |
| 独立读回与失败恢复 | 写后另一次读取实际产物；工具能报告失败与已提交状态，未知时先查现场；不以写入参数充当结果 |
| 场景与视觉证据 | 任务适用时能分别观察 Web/Desktop，且能取得所需视觉证据；禁止截图时遵守并保留缺口 |
| 记录与校验 | 能保存原始返回和任务记录，并在 Python 3 环境实际执行本包校验器；命令名可不同，结果要求不变 |

先核对文档与权限；写入能力只在本次已授权目标或测试副本验证。没有授权时不创建测试页。能力检查通过只支持所测范围，不能承诺整个平台、所有文件或所有组件可用。某能力缺失时继续其他不受影响项。

## 资源与产物位置

- 包内文件相对当前 `SKILL.md` 所在目录定位；不要依赖启动工作目录、固定用户名、macOS 路径或 Codex 安装目录。平台只提供资源标识时，用实际资源标识读取并记录。
- `bohrium-design-language`、Figma 操作规范与组件索引是外部依赖，不随本包自动提供。通过当前平台资源列表、工作区登记或用户指定位置查找，核对内容、版本与权威性；同名不保证同一份。
- 组件专文写入用户项目的文档维护位置，原始证据写入任务输出位置；安装副本不作为业务产物默认存放地。没有本地磁盘时可使用平台可读回、可导出的附件或文档存储，记录真实位置。
- 找不到权威索引或无写权限时保存待同步条目，写明目标缺口，继续独立可做项；不新造第二个权威索引，不冒称已同步。
- 飞书、18:00 集中同步及指定接收者属于工作区约定；只在当前工作区明确有此要求时执行。换平台不自动创建提醒、发消息或发布。

## 缺少能力时

| 缺失 | 可以完成 | 必须保留的边界 |
| --- | --- | --- |
| Figma 写入或构建 | 实读盘点、有依据的文案、差异与方案 | 远端未修改；截图、链接或普通图形不冒充真实实例 |
| 变量、实例链或独立读回 | 继续能观察的范围 | 对应绑定、来源或写后检查未验证，不以外观代替 |
| Python 或命令执行 | 导出真实证据、contract/report 和待运行命令 | 校验器未运行；不伪造检查输出、哈希或退出码，不宣称整体验收通过 |
| 文件读取不完整 | 明确已读范围，整理有据部分 | 未读取的规则和证据不声称已执行 |
| 业务入口或必要视觉证据 | 继续授权范围内独立可做项 | 逐端区分未尝试、受阻、未找到、已观察；必要视觉项未验证 |

## 兼容性如何报告

分开记录：包可读取、Skill 被实际加载、记录程序可运行、Figma 只读、代表写入与读回、完整任务验收。每项附平台/版本、包摘要、工具、日期与证据；未测试的平台只写未验证。文字推演与复制到模拟目录不算在该平台真实运行；一台机器运行 Python 不证明所有操作系统通过。

维护时执行 [跨平台回归题](../validation/platform-cases.md)。本文件定义适配要求，不承诺任何未知平台已通过。
